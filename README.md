## Function Parameters and Return Values

A simple student grade analyzer created to practice Python functions and the reuse of returned values.

### Concepts practiced

- Creating functions with `def`
- Function parameters and arguments
- Returning values with `return`
- Variable scope
- Passing the result of one function to another
- Conditional statements
- F-strings

### How it works

The program calculates the average of three grades using the `calculate_average()` function.

The returned average is then passed to `classify_student()`, which determines whether the student is approved or failed.

Input:

calculate_average(8, 7, 9)# python-foundations
